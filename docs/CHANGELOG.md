### 识别侧：三个新模块 + 一处镜像裁决

- **`features/height_zones.py`（高度分解）**。读法 = 两路证据的乘积：
  ① **分区从哪来**——俯视图（正对轮廓面）的圆按轴共线分组、组内**半径序奇偶
  定角色**（最外=材料边界、次外=孔、再次=材料…），等径材料圆两两相配 ⇒
  切线凸包（长圆/跑道面），配对前用**图纸自己的切线**核实（防"两个独立凸台"
  误并，见 `_stadium`）；② **每区多高**——侧视图可见轮廓环逐点求上下包络，
  对分区在 b1 上的投影取 top=min/底=max（分区只有自己当顶/当底的那几列算数），
  基体降到轮廓区间内**最低顶面**、其余分区自它向上抬。抬升区 = BASE 段、
  长圆槽 = POCKET、圆孔 = HOLE（全部用现有表达，不加新参数）。不分解条件
  （一律记账，不猜）：剪影平（≤`UNIFORM_TOL` ⇒ 板件，block_3view /
  plate_100x60 走这条逐位不变）、剪影不平但轮廓内无轴∥拉伸方向的圆、
  带 `taper_scale`、REVOLVE。侧轴凸台的轴向区间由 `side_axis_spans` 读
  （旧读成 3.00 薄壁缘，实为挂耳 r12 的轴向跨度）。
- **`features/roundovers.py`（顶边凸圆角 + 根部凹圆角）**。信号 = 正视图里
  两条此前没人看的层线：z=顶面−R 的切线（凸）、z=顶面+R 的切线（凹）。
  凸圆角把轮廓环里共线连续的直段并成 run、过**四道门**（共线合并角 ≤
  `MERGE_ANG_DEG` / run ∥ ±b1 / 图纸可见 run 覆盖 / u 区间内其余点在材料侧），
  在 bracket 上精确复现金值 6 段 {114,115,116,119,120,121}——一条不多一条
  不少；凹圆角把层线 run 投到分区足迹反解角域 θm=57.8°，侧视图
  [134.13,167.98] 独立互证。发射侧：OCC 的 `BRepFilletAPI` 在本零件 IsDone
  恒 False ⇒ **工具式扫掠**（逐段刀 Cut + `_mate_prisms` 避让）+ 回转补料；
  SW 走原生圆角 + 中面回转（Dir1Type=6，新增 `swEndCondMidPlane=6`）。
- **`features/side_channels.py`（挂耳三结构）**。**月牙缺口**（挂耳悬空
  z∈[12,36]，基体却把俯视轮廓整片拉到板厚 ⇒ 下方假料；刀 = 凸台条带 −
  倚靠的材料圆盘，自板底切到板顶）、**张缝**（关于凸台轴向中点对称的一对
  平行线，贯穿全高，见 bracket 夹紧结构）、**销孔**（跨凸台全轴的一对轮廓线，

### SW 基体拉伸破冰（同日的发射器修复，`emit/sw_builder._sketch_profile`）

症状：bracket 基体在 SW 里 **`FeatureExtrusion2` 返回 None**（OCC 侧早已成功），
122 段带弧轮廓拉伸全败。bisect 探针（`_probe_sw_arc_bisect.py`，40+ 变体）
定出**两个独立触发因**，并各配一条修复：

1. **碎片线链**：SW 草图求解器拒绝"30+ 段首尾相接的碎片微线段链"——同一 U 形槽
   两排碎片链，**任一排**合并、另一排保留碎片即可通过；两排都碎片时 5 个变体全败；
   122 实体（未合并）连**纯折线环**都拉不出来（`chords` 变体实测失败）。
   修复 = **精确共线无损合并**（叉积 ≤1e-9·|a||b|，垂偏实测 0.000µm、合并前后环
   解析面积逐位相同 8347.756mm²；122→62 实体）。
2. **顺时针劣弧的调用形态**：四点实验（r10 角区，正确短弧 214.602 / 补弧 3356.194）
   + bisect 定死 SW 的 `CreateArc` 语义**与文档不符**：`direction=True` 实测 =
   **顺时针**；`direction=False` 实测 = **取劣弧**（CCW 走优弧时会把劣弧画出来——
   cwF 反例）。bracket 两条 r3 顺时针劣弧按"几何正确"传 True 会**静默拒绝拉伸**，
   传 False 通过且几何正确（`mx119flip`/`mxfo2` 实测）。修复 = **span ≤ π 的弧
   一律传 False**；优弧用"顺时针 + 正确端点序"表达（换序走顺时针 = 同一条优弧）。
   旧 `cross<0` 判据只保留在优弧分支。

**验证（SW 验收表实测）**：6 个简单靶子 + l_bracket + 图形练习 = **8 绿，体积
逐位**（防回归 ✅）；**bracket 三视图 8 特征 → SW 8（步数一致），体积 361,379.4**
——与 OCC 侧 361,044.7 **两个独立发射器吻合到 0.09%**（+88.23% vs +88.06%，
