## 2. 问题清单（按性质分级）

### A. 信息论天花板（图纸里没有该信息——记账、不修）

1. **融合投影天花板**：出图侧逐实体 Fuse 抹掉 CSG 交界线信号——旧管线剖面图纸路径 +3.81~4.23% 的根源；新框架剖面图纸 +0.11%，此条只约束旧管线（已停更）。
2. **bracket 臂区方块**（旧管线剖面路径特有）：新框架 bracket −0.01% 不含此误差，随旧管线停更。
3. 信息论局限表其余条目：F 段顶 3mm 环、φ3.3 沉头锥、φ3.3/φ5.5 孔位 0.1mm 差、顶段角凸 16 边近似 −156、bracket 凸台 z[22,24] 两侧槽无信号。

### B. 新框架残余精度（已记账，可追可不追）

- **PF60K +163.7（+0.06%）**：逐段落点已定位——+1,005.3（z[0,6]＝图纸 z[28.5,34.5]，r=8 台阶过实）／−852.5（z[−8,−4]＝图纸 z[20.5,24.5]，锥区欠料）+ 微项 +11.3。薄板探针 `_probe_pf60k_slabcmp.py` 备好。绿行上的残余，等新证据再动。
- SW 表 bracket 比 OCC 高 ~+1.06k 系发射器口径差（圆角区盒探针两发射器差 ≤0.4mm³），早于阶段 7。

### C. 图纸理解层缺口（新框架下一台阶）

1. **局部剖/半剖无识别**（YZYX 的 C—C 半边剖）——靠手工读图兜住的读法未进 `conventions/`。
2. **细实线 = 被顶壁盖住的轮廓**（#1 三轮才收敛的读法）未沉淀为约定。
3. **DIMENSION 实体当尺寸证据**（`get_measurement` 实测「20/3/120」定案）未制度化——证据挖掘第一轮就该做。
4. 断裂视图识别（阶段 2 已有）尚未消费进特征层。

### D. 验证体系盲区（比精度更值得记的一条）

- 自动指标（体积 / bbox / 重合率）到 **99.5%+ 时局部可见缺陷仍然存在**——bracket 三缺陷、YZYX 四五处标记均为用户目视发现，自动验证零命中。
- 无 3D 基准的靶子（YZYX）无法定量验收：投影评分 + 材料探针 + 用户目视。
- 渲染对照（`_render_dxf.py`）、截面叠加（`_dump_sections`/`_draw_sections`）、viewer（`_make_viewer.py`）工具备齐，但未制度化进每次修复流程。

### E. 工程债 / 产品化

1. **GUI 起不来**（三解释器均无 PyQt6）；`src/` 侧 GUI 与算法全骨架；三套实现并存（旧管线 / `src/core` 骨架 / `src/rebuild`）。
2. `sw_driver.disconnect()` 收尾会关活动文档（用户要求先冻结不动）。
3. tag `v0.6.22-3-g01b0754` 落后 3 个提交，版本簿记待例行收口。
4. 根目录 294 个 `_*.py` 一次性脚本（YZYX 一族 70 个）——gitignored 但目录噪音大。
5. SW COM 工程图「只有一个视图」（91+ 天前记录，未复核）。
6. `src/core/reconstruction/` 已判定过时，待删除。

### F. 工作流弱点（自评）

1. **大复杂件（YZYX 级）自动管线读不动**，最终靠手工参数化收敛：15 版迭代 + 用户 4 轮读法闭环。可靠但慢，且不可复用（70 个脚本 = 单件专用）。
2. **制图约定误判**：把「细实线 = 被顶壁盖住的轮廓」读成「开口」（#1 争议三轮才收敛）；旧把 R8_5 当 R8（新框架已解）。纠错靠反事实模型 / 材料探针 / 尺寸实体实测，成本高。
3. **无基准件把验收压力转移给用户**：交付前给不出与有基准靶子等价的定量置信度。
4. **证据挖掘第一轮深度不够**：#1 直到第三轮才把图纸自带 DIMENSION 实体挖出来实测——但「HLR 重合消影推理」通道（2026-10-10）是机器侧自动挖证据的第一步，方向对。

## 3. 优先级建议

1. **约定沉淀进 `conventions/`**（§C1~C3）：局部剖/半剖、细实线=被盖轮廓、DIMENSION 实体证据——YZYX 手工读图知识前移，是下一批靶子（含局部剖图纸）能读的前提。
2. **验证制度化**（§D）：渲染对照 + 截面叠加 + 盒探针列为每次修复的例行检查，把「用户目视」前移。
3. **PF60K 残余 +163.7**（§B）：逐段落点已明，追到逐位是可选追求。
4. **工程债收口**（§E3~E6）：tag 簿记、脚本归档、`reconstruction` 删除、SW 工程图多视图复核——低风险低成本。
5. GUI / 产品化留到最后（当前工作流不依赖）。
