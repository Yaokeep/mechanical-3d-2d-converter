### C. 图纸理解层缺口（新框架下一台阶）

1. ~~局部剖/半剖无识别~~——**已收口（2026-10-11，v0.6.23）**：`_DIRECTION_LABEL_RE` 读「c 向」式标题 + `section.scope` 剖面线覆盖比几何推断（≥0.9 full / <0.9 local + 疑问）+ `section.material` 读 LINE 画法剖面线。实测 YZYX C—C 定性 section、scope=local。
2. ~~细实线 = 被顶壁盖住的轮廓~~——**已收口（2026-10-11，v0.6.23）**：`Role.THIN` + `linetype.thin` 约定，环提取 `_PROFILE_ROLES` 只认 VISIBLE 自动排除。实测 YZYX 35 条。
3. ~~DIMENSION 实体当尺寸证据~~——**已收口（2026-10-11，v0.6.23）**：`dimension.anchors` 规则做「数值 ↔ 几何锚点」配对（tier=ANNOTATED）。实测 YZYX 52 条读出、45 锚上，20/3/120 逐位吻合。
4. ~~断裂视图识别尚未消费进特征层~~ → **仍有靶子（2026-10-12 修正）**：此前
   按"线型/图层名"扫描 `CAD/**` 89 份 DXF 得"真实图纸零命中"，据此判无靶子；
   YZYX 实证该扫描**漏了**画在**细实线**层、以 **SPLINE** 表达的波浪断裂线
   （`8A9`，bbox 与「c 向」窗口逐位重合）。识别层（`linetype.breaks`）已就绪且
   作为守卫在用（`recognizer.py:288` 把断裂轴列为"坐标不可用"防线），当前把
   `8A9` 读成 `role=thin`（按图层，正确但不完整）。"消费进特征层"（按断裂画法
   还原/或据此收缩视图范围）**有靶子可做**，但优先级低于 §C5 剩余项——认定
   断裂线需要**几何形状**判据（波浪/正弦样条）或**语境**判据（局部视图边界），
   不是读图层名。
5. ~~密集大图视图分离（YZYX）~~ → **已收口（2026-10-12）**，三堵墙依次拆掉：
   ①图框+家具混入（`_frame_by_long_lines`/`_sheet_frame`，剥框后阈值 71.28/50.40
   → 47.29/34.86）；②两段式聚类结构性失效（同列上下堆叠视图被邻列 y 跨度遮住
   ⇒ 递归 `_xy_cut`）；③2×N 布局主视图判据失效（"恰好一个视图有行有列"只对 L 型
   成立 ⇒ 三等定律 `_extent_score` 裁决，V1 +2 唯一最大）。实测 5 视图逐位对上、
   特征树 0 → 22。**剩下的是 §C6 特征识别**（见下条）。
6. **【新，2026-10-12】密集大图的特征识别（YZYX，下一堵墙）**——`--force` 照建
   体积 **+394%**（38,437,062 vs 7,782,529.65），bbox z 375 vs 203；107 项拦路
   疑问里 98 项是"V3 中心线定出 3D 轴但图纸没给半径"（即：**轴线读出来了、特征
   没读出来**）。已记账的"`axial_at` 缺省按 0 起"静默默认也参与其中。
   两个直接可做的抓手：①V3 中心线 → 轴 → 找等半径轮廓对（现在是"找不到间距 2r
   的轮廓对"就记缺口，应升级为**用尺寸标注/剖面视图补半径**）；②V2 局部剖的
   剖切位置未知 ⇒ 拿不到它的视图坐标系（`_yz_hlr` 的 `SPLIT_X` 也是零件系常量）。
   **验收前提**：无基准三件套（27 点材料探针 + HLR 五视图评分）建在 **v15a 零件
   系**上，而新框架模型在**图纸坐标系**（平移 + 轴序不同）⇒ 给新框架模型打分前
   必须做零件系变换（否则 11 个"期望 IN"点全落空、TL/TR 视图空——2026-10-12
   实测就是这个假象）。

### F. 工作流弱点（自评）

1. **大复杂件（YZYX 级）自动管线读不动**——2026-10-12 首跑量化了第一层："视图分离先把 5 视图并成 1 个、特征树 0 条"（§C5）——**当日即收口**（5 视图逐位对上、特征树 22 条）；第二层（特征识别）用 `--force` 模型量化为 **+394%**（§C6），留作下一轮。此前最终靠手工参数化收敛：15 版迭代 + 用户 4 轮读法闭环。可靠但慢，且不可复用（70 个脚本 = 单件专用）。
2. **制图约定误判**：把「细实线 = 被顶壁盖住的轮廓」读成「开口」（#1 争议三轮才收敛）；旧把 R8_5 当 R8（新框架已解）。纠错靠反事实模型 / 材料探针 / 尺寸实体实测，成本高。
3. **无基准件把验收压力转移给用户**：交付前给不出与有基准靶子等价的定量置信度。
4. **证据挖掘第一轮深度不够**：#1 直到第三轮才把图纸自带 DIMENSION 实体挖出来实测——但「HLR 重合消影推理」通道（2026-10-10）是机器侧自动挖证据的第一步，方向对。
